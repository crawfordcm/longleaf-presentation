# Getting Started with Longleaf

This repository contains the material and website introducing UNC's Longleaf computing cluster. 

**Website:** [Getting Started with Longleaf](https://crawfordcm.github.io/longleaf-presentation/)

## Workshop outline

1. [Introduction to Longleaf](modules/01-introduction/01-computing-history.qmd)
2. [Accessing Longleaf](modules/02-accessing-longleaf.qmd)
3. [Interacting with Longleaf](modules/03-interacting-with-longleaf/01-working-on-longleaf.qmd)
4. [R on Longleaf](modules/04-r-on-longleaf.qmd)

## Repository structure

- `index.qmd` — clickable workshop outline and homepage
- `modules/` — the presentation/tutorial modules, with separate pages grouped into module folders where needed
- `examples/` — downloadable R and Slurm examples as they are developed
- `images/` — diagrams, screenshots, and the site icon
- `styles.css` — the shared visual design
- `_quarto.yml` — navigation and site settings
- `docs/` — the generated website used by GitHub Pages
